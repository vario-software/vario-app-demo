# VARIO App Demo

This is a demo app built with the [VARIO App Framework](https://github.com/vario-software/vario-app-framework) and demonstrates how to develop and run a VARIO Cloud App using Node.js.

## Getting started

[Follow the VARIO Cloud App Quickstart](https://developer.vario-software.de/documentation/apps/quickstart) — it walks you through registering an App, configuring this demo and running it inside VARIO Cloud.

```bash
git clone https://github.com/vario-software/vario-app-demo.git
cd vario-app-demo
npm install
```

Then add your App credentials to `app-client.js`, align `app-manifest.json` with the App you registered, and start the app:

```bash
npm run dev
```
